O que é o CSS?

O CSS significa Cascading Style Sheets ou folhas de estilo em cascata.

Sobre o CSS

Linguagem responsável por definir a aparència visual dos elementos na tela

Como aplicar o CSS

Para o CSS. temos très abordagens

  • CSS Inline
  • CSS Interno
  • CSS Externo

O que da para fazer com o CSS

O CSS não serve apenas para colocar cor na página. ele controla:

  • cores
  • fontes
  • tamanhos
  • espaçamentos
  • sombras
  • bordas
  • posicionamento
  • reponsividade
  • animações
  • transições

Aplicando o CSS Inline

Nessa abordagem, o CSS é colocado diretamente nos elementos HTML usando o atributo style.

Aplicando o CSS Interno

Nessa abordagem, o CSS é colocado dentro da tag <style> <head> do documento HTML.

Aplicando o CSS Externo

Nessa abordagem, os estilos do CSS ficam concentrados em um arquivo separado

Para conectar esse arquiivo ao HTML, utilizamos o elemento de <link> no <head> da página.
